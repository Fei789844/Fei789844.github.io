# AI-native 数据产品作品集

三个可离线运行的交互式看板，展示将业务问题转为指标、筛选与可视化，并使用 AI 辅助实现和验证的过程。

- [客户 AI 使用分析](ai-usage.html)：使用趋势、功能分析和留存。
- [用户生命周期](lifecycle.html)：注册、绑定、激活、首用与状态对账。
- [用户活跃](activity.html)：周期去重、增长、留存、流失和异常明细。

所有名称、功能、用户编号、日期和业务数字均为匿名编码或独立模拟数据，不代表真实客户表现。文件不包含公司后台接口、凭证、原始明细或名称映射。

这些演示展示了业务指标建模、AI 辅助实现、交互设计、数据脱敏和验证能力；不以模拟指标证明真实业务增长。

下载 HTML 后可直接用浏览器打开。GitHub 仓库文件页展示源码；部署 GitHub Pages 后可在线交互浏览。
