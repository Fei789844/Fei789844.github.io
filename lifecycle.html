05 统计口径与脱敏说明

已注册 / 已绑定

注册日期不晚于快照日即已注册；已注册且存在截至当日有效的设备绑定即已绑定。仅设备 A 表示有设备 A，且无设备 B / C 绑定。设备 B 和 C 可同时存在，不相加作为去重总人数。

模块 X 激活 / 服务 A 首用

模块 X 需要设备 C 已绑定且模拟激活日期不晚于快照日；服务 A 首用为演示历史中出现对应能力的主动行为。两者独立判断，不组成必经漏斗。

首用与当前状态

首用用户中，快照当天有行为为活跃；距最近行为 1–6 天、7–13 天分别记为两档沉默；满 14 天未使用记为流失。四档人数之和等于首用人数。

日期和分母

矩阵每列为一天快照，最新状态取结束日。绑定率＝绑定人数÷注册人数；模块激活率＝激活人数÷设备 C 绑定人数；各当前状态占比以全部首用人数为分母。无分母时显示“—”。

全部独立模拟

保留参考看板的模块和交互，重新生成用户、绑定、激活和行为历史。日期、数字和分布均非原数据变换；不存在真实编号映射表，也不附带后台数据或内部地址。

离线使用

无需账号或网络。筛选联动快照、趋势、状态和核对表；矩阵可收起比率、前后翻页，图表可切换线 / 柱、开关图例，表格可排序、翻页及导出模拟 CSV。
